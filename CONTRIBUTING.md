# 🤝 Contributing to MidnightLedger 💜🌙

Thanks for checking out MidnightLedger! ✨

### 🚀 How to Contribute
1. 🍴 Fork the repo
2. 🌿 Create your branch: `git checkout -b feature/amazing-feature ✨`
3. 💾 Commit: `git commit -m 'Add amazing feature 💜'`
4. 📤 Push: `git push origin feature/amazing-feature`
5. 🔀 Open a Pull Request

### 🐛 Bug Reports
Use the bug report template! Include:
- 📱 Device / browser
- 📝 Steps to reproduce
- 📸 Screenshot if possible 🌙

### ✨ Feature Requests
Open a feature request issue — we love new ideas! 💜

### 💜 Code Style
- ⚛️ React + TypeScript
- 🎨 Keep OLED dark theme #0A0A0A + purple #7C3AED
- ✨ Keep the cozy midnight vibe 🌃
